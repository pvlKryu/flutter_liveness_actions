# Disclaimer

`flutter_liveness_actions` is **not** an identity verification SDK.

It is **not** biometric authentication, KYC, AML, fraud prevention, credit decisioning, or a regulated compliance product.

The package provides liveness-aware face-action **derived signals** and challenge-flow utilities for demos, prototypes, research, and mobile onboarding UX helpers.

Developers are responsible for legal, privacy, compliance, and security review before any production use.

Do not use this package as the sole security mechanism for onboarding, lending, account opening, or regulated workflows.
