# Security

## No security guarantees

This package provides no security guarantees. It must not be used as the only anti-fraud or account-protection measure.

## Biometric data

Do not store raw biometric data without proper legal basis, user consent, and security controls. This package disables raw image storage by default.

## Vulnerability reports

Report vulnerabilities via [GitHub Issues](https://github.com/pvlKryu/flutter_liveness_actions/issues) or by contacting the maintainer at pavkriuchkov@gmail.com.

If the issue involves sensitive security details, prefer email first.

## Defaults

- `rawImagesStored = false`
- `derivedSignalsOnly = true`
- No raw image APIs in the core public surface
